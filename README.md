# vuln-reports

Security vulnerability reports for open-source PHP applications, each with
local reproduction evidence (PoC requests/responses and screenshots).

## Scope

Reports cover source-coder portfolio web applications (inventory/ERP-scale to
small utilities). Every finding was reproduced on a local instance
(127.0.0.1) before documentation; no testing was performed against public
deployments.

## Layout

- `<project>/NN-<type>.md` — one report per finding
- `<project>/img/` — reproduction screenshots
